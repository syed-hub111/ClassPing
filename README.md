# ClassPing

A Tuition Attendance Management App built with Flutter and Firebase Cloud Functions.

## Features
- **Admin Dashboard**: Academic year tracking, class & student management, tutor assignments, and promotion management.
- **Tutor Portal**: Daily attendance marking and verification.
- **Parent Portal**: Attendance history tracking, student attendance comparison, notifications, and tutor contact info.
- **Cloud Backend**: Firebase Cloud Functions, Firestore triggers, and scheduled notifications.

## Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Node.js](https://nodejs.org/) (for Firebase Functions)
- [Firebase CLI](https://firebase.google.com/docs/cli)

### Flutter Client Setup
1. Install dependencies:
   ```bash
   flutter pub get
   ```
2. Run the application:
   ```bash
   flutter run
   ```

### Firebase Functions Setup
1. Navigate to the functions directory:
   ```bash
   cd functions
   npm install
   npm run build
   ```
